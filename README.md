## 前言

本程序旨在提供一个轻量级的本地网址收藏夹，方便集中管理和快速访问常用网站。本项目追求简单、开箱即用，非常适合个人网址整理。

* **零依赖：** 无需数据库、无需服务器、无需安装任何额外环境，下载后即可离线使用。
* **公网部署：** 如需部署到公共网络环境，只需上传主页 `index.html` 和配置文件 `link-data.js` 即可。

## 使用说明

* **数据存储与格式：** 数据统一存储在当前目录的 `link-data.js` 文件中。数据格式为数组，每个元素包含 `name`（名称）、`url`（地址）、`icon`（图标URL）和 `cat`（分类）等属性。
* **分类管理：** 链接分类可自定义，主页 `index.html` 会动态生成并按分类展示。在后台新建链接时，建议最后选择分类，保存后链接会自动跳转并归入该分类下进行显示。
* **数据编辑与保存：** 您可以直接运行 `admin.html` 进行可视化编辑，或使用文本编辑器修改 `link-data.js`。保存时请选择替换原文件，**强烈建议在修改前进行备份**，以免数据丢失。

## 安全与加密 (v1.02 更新)

为加强隐私保护，避免被恶意软件扫描，v1.02 版本引入了密码访问与数据加密功能（密码经 MD5 方式保存）。

* **按需切换加密方式：** 压缩包内提供 `Aes`、`base64`、`明文` 三个目录。它们核心文件相同，仅保存方式不同，下载其一即可，并支持自由切换。
* **无密码模式：** 使用 `明文` 或 `base64编码` 方式保存数据，访问无需密码。
* **AES加密模式：** 使用 `AES` 方式保存数据，默认访问密码为 `www.ximi.me`。
* **新增依赖：** v1.02 新增 `crypto-js.min.js` 和 `md5.js` 两个依赖库文件，请勿删除。
